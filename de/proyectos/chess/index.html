Chess Engine

Eine vollständige Schach-Engine von Grund auf: Spiellogik, Zugregeln je Figur und Partieverwaltung im Backend, über eine REST-API bereitgestellt und von einem eigenen JavaScript-Frontend konsumiert.

Python FastAPI Pydantic REST API JavaScript unittest Schichtenarchitektur

Architektur

Das Projekt trennt die Verantwortlichkeiten in unabhängige Schichten, statt Spiellogik und API zu vermischen:

model/

Spielbrett, Figuren und Zugregeln jeder Figurenart.

services/

Partieverwaltung (MatchesService): Erstellung, Züge, Validierung.

backend/

REST-API mit FastAPI: Endpoints, Request-/Response-Modelle mit Pydantic, CORS.

frontend/

Interaktives Spielbrett in HTML/CSS/JavaScript, das die API nutzt.

tests/

Unit-Test-Suite (unittest) für Figuren, Spielbrett und Partien.

REST-API

Wichtigste vom Backend bereitgestellte Endpoints:

POST/api/registerSpieler registrieren
POST/api/matchPartie zwischen zwei Spielern erstellen
GET/api/match/activeaktive Partie eines Spielers (Polling)
GET/api/match/{id}/boardSpielbrettstatus
GET/api/match/{id}/moveslegale Züge einer Figur
POST/api/match/{id}/moveZug ausführen

Tests

✓ Abgedeckt durch Unit-Tests (unittest): Erstellung von Figuren, Spielbrett- und Partielogik.

Quellcode

Vollständiger Quellcode, nach Ordnern durchsuchbar:

model/ services/ backend/ frontend/ tests/
