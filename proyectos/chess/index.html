Chess Engine

Motor de ajedrez completo construido desde cero: lógica de juego, reglas de movimiento por pieza y gestión de partidas en el backend, expuestos a través de una API REST y consumidos por un frontend propio en JavaScript.

Python FastAPI Pydantic REST API JavaScript unittest Arquitectura en capas

Arquitectura

El proyecto separa responsabilidades en capas independientes, en vez de mezclar lógica de juego con la API:

model/

Tablero, piezas y reglas de movimiento de cada tipo de pieza.

services/

Gestión de partidas (MatchesService): creación, turnos, movimientos, validación.

backend/

API REST en FastAPI: endpoints, modelos de petición/respuesta con Pydantic, CORS.

frontend/

Tablero interactivo en HTML/CSS/JavaScript que consume la API.

tests/

Suite de pruebas unitarias (unittest) sobre piezas, tablero y partidas.

API REST

Endpoints principales expuestos por el backend:

POST/api/registerregistrar jugador
POST/api/matchcrear partida entre dos jugadores
GET/api/match/activepartida activa de un jugador (polling)
GET/api/match/{id}/boardestado del tablero
GET/api/match/{id}/movesmovimientos legales de una pieza
POST/api/match/{id}/moveejecutar un movimiento

Pruebas

✓ Cubierto por tests unitarios (unittest): creación de piezas, lógica de tablero y de partidas.
